# PROYECTO_FINAL_EPBI
Proyecto reproducible en Python que construye el Economic Perception Bias Index (EPBI) con microdatos de la European Social Survey y datos de Eurostat. Integra variables individuales y contexto macroeconómico, estima modelos WLS con efectos fijos y genera resultados preparados para un dashboard interactivo en Excel con VBA para análisis en Europa.
